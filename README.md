# README - what this workspace is and where to start

This workspace re-brands the schematic sheet templates on Altium Designer projects: it inventories each project, plans the swap, runs an Altium script, and verifies the result from the files on disk.

Start with [setup/prerequisites.md](setup/prerequisites.md).

Test status: the Python tools were run on 85 real `.SchDoc` files from public GitHub projects, but the Altium script has never been run in Altium.
